# Загрузка отпусков (Курсор)

Внешняя обработка загрузки пакетов отпусков из Парус в 1С:ЗУП (ЦБУ).

## Структура каталога

| Каталог | Назначение |
|---------|------------|
| `src/` | Актуальные исходники (v8unpack: JSON + BSL). Рабочая копия для правок. |
| `releases/` | Собранные EPF по версиям. Каждая версия — отдельный файл, не перезаписывать. |

## Версионирование

- **Имя EPF:** `ЗагрузкаОтпуска_Курсор_ГГГГММДД_NN.epf` (`NN` — порядковый номер сборки за день).
- **В коде:** функция `ВерсияОбработки()` в `src/ExternalDataProcessor.obj.bsl` — та же строка `ГГГГММДД_NN`.
- При каждой сборке: правки в `src/` → обновить `ВерсияОбработки()` → собрать EPF → положить в `releases/` → **закоммитить и запушить** (см. ниже).

## Git

Удалённый репозиторий: [github.com/EugenE1336/eugene1336.github.io](https://github.com/EugenE1336/eugene1336.github.io)

После каждой доработки — коммит и push обязательны:

```powershell
git add "Конфигурации/ЦБУ/Отпуск/Обработки/ЗагрузкаОтпуска_Курсор/src/" `
        "Конфигурации/ЦБУ/Отпуск/Обработки/ЗагрузкаОтпуска_Курсор/README.md" `
        "Конфигурации/ЦБУ/Отпуск/Обработки/ЗагрузкаОтпуска_Курсор/releases/ЗагрузкаОтпуска_Курсор_ГГГГММДД_NN.epf"
git commit -m "ЗагрузкаОтпуска_Курсор: версия ГГГГММДД_NN — краткое описание"
git push origin main
```

EPF в каталоге `releases/` — в git; копии EPF рядом с каталогом обработки (в `Обработки/`) — локальные, в `.gitignore`.

## Сборка EPF

Требуется Python и [v8unpack](https://pypi.org/project/v8unpack/):

```powershell
python -m v8unpack -B "src" "releases/ЗагрузкаОтпуска_Курсор_ГГГГММДД_NN.epf"
```

Запускать из каталога `ЗагрузкаОтпуска_Курсор/`.

## Разборка EPF в исходники

```powershell
python -m v8unpack -E "releases/ЗагрузкаОтпуска_Курсор_ГГГГММДД_NN.epf" "src" --temp "../temp_unpack"
```

После разборки проверить `src/ExternalDataProcessor.obj.bsl` и не коммитить каталог `temp_unpack`.
